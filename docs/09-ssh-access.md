# Настройка SSH-доступа

Три независимые настройки. Выполняются один раз.

Плейсхолдеры: `<IP_сервера>` — IP-адрес сервера; `<имя>` — произвольное имя, выбираемое
для удобства.

| Что | Результат |
|---|---|
| [Вход по ключу](#1-вход-по-ключу) | пароль больше не запрашивается |
| [Отображаемое имя сервера](#2-отображаемое-имя-сервера) | в терминале видно `root@<имя>` вместо `root@<IP_сервера>` |
| [Короткое имя для подключения](#3-короткое-имя-для-подключения) | вместо `ssh root@<IP_сервера>` достаточно `ssh <имя>` |

---

## 1. Вход по ключу

**На рабочей машине** — проверка наличия ключа:

```sh
ls ~/.ssh/*.pub
```

При отсутствии ключа он создаётся:

```sh
ssh-keygen -t ed25519 -C "<имя>"
```

`<имя>` — лишь подпись (комментарий) ключа, например `macbook`; на работу ключа она не
влияет. Команда создаёт универсальный SSH-ключ рабочей машины, а не ключ для конкретного
сервера или подключения: один ключ подходит для любого количества серверов.

На вопросы можно отвечать Enter. Парольная фраза для ключа необязательна, но
рекомендуется.

**Передача открытого ключа на сервер:**

```sh
ssh-copy-id root@<IP_сервера>
```

Пароль запрашивается в последний раз. Проверка:

```sh
ssh root@<IP_сервера>
```

Подключение проходит без пароля.

## 2. Отображаемое имя сервера

Сетевое имя (hostname), которое отображается в консоли сразу после `root@`. Настраивается
внутри системы сервера:

```sh
hostnamectl set-hostname <имя>
```

Чтобы имя разрешалось локально, оно добавляется в `/etc/hosts`:

```sh
sed -i "s/^127.0.1.1.*/127.0.1.1\t<имя>/" /etc/hosts
grep -q '^127.0.1.1' /etc/hosts || echo -e "127.0.1.1\t<имя>" >> /etc/hosts
```

После переподключения в приглашении — `root@<имя>`.

Имя произвольное: латинские буквы, цифры и дефис. На работу установленных конфигураций
оно не влияет.

---

## 3. Короткое имя для подключения

Настраивается на рабочей машине, в `~/.ssh/config`:

```sh
nano ~/.ssh/config
```

В конец файла добавляется блок, где `<имя>` — короткое имя для подключения:

```
Host <имя>
    HostName <IP_сервера>
    User root
```

Сохранение: `Ctrl+O`, Enter, затем `Ctrl+X`. Для только что созданного файла:

```sh
chmod 600 ~/.ssh/config
```

После этого достаточно:

```sh
ssh <имя>
```

---

## 4. Подключение в скриптах проекта

При установленном ключе вход выполняется по ключу: в поле пароля достаточно нажать
Enter. Без ключа вводится пароль пользователя. Если вход не удался, скрипт предлагает
повторить ввод пароля — не больше трёх раз; Enter завершает работу.
