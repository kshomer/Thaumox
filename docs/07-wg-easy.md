# WireGuard с веб-панелью wg-easy — скрипт 09

---

## Особенности

- **Классическая частная сеть.** Удалённый доступ к собственной домашней или рабочей
  сети, связь между серверами, подключение доверенных устройств.
- **Клиенты создаются в веб-панели.** Скрипт разворачивает панель; создание клиентов,
  QR-коды и файлы конфигурации — в браузере.
- **Управление — только через веб-панель.** Менеджер `00-manager.sh` для wg-easy не
  используется.

---

## Что спросит установщик

1. **Подключение к серверу** — IP-адрес, порт SSH, пользователь, пароль.
2. **Доступ к панели** — главный выбор:

   | Вариант | Что означает |
   |---|---|
   | **Только через SSH-туннель** (по умолчанию) | порт панели слушает `127.0.0.1`, снаружи панель недоступна |
   | **Открыть в интернет** | панель доступна всем по HTTP, без шифрования |

3. **Порты** — `51820/udp` для WireGuard и `51821/tcp` для панели.
4. **Прежняя установка**, если найдена: обновление с сохранением клиентов, установка
   заново с удалением всех данных или отмена.

---

## Безопасность панели

Панель работает только по HTTP. Открытая в интернет, она передаёт логин, пароль и
сессию открытым текстом.

> Закрыть уже опубликованный Docker порт правилом `ufw` нельзя: Docker публикует его
> правилом DNAT в цепочке `nat/DOCKER`, и трафик идёт мимо цепочек ufw. Надёжный
> способ — не публиковать порт наружу.

Поэтому по умолчанию выбран SSH-туннель. В конце установки установщик предлагает один
раз дописать проброс порта в локальный `~/.ssh/config` — автоматически или по
пошаговой инструкции.

## Первичная настройка

При первом входе панель запускает мастер настройки:

1. «Welcome to your first setup of wg-easy» — **Continue**.
2. «Please first enter an admin username and a strong secure password» — логин и пароль
   администратора панели.
3. «Do you have an existing setup?» — **No**.
4. «Please enter the host and port information» — host: IP-адрес сервера; port: порт
   WireGuard (обычно уже подставлен).

## Вход в панель

**Доступ через SSH-туннель.** Сначала — подключение к серверу в терминале:

```sh
ssh root@<IP_сервера>
```

Затем, не закрывая сессию, панель открывается в браузере по адресу
`http://127.0.0.1:51821/`.

**Доступ из интернета.** Панель открывается в браузере по адресу
`http://<IP_сервера>:51821/`.

Порт панели по умолчанию — `51821`; при выборе другого порта адрес меняется
соответственно.
