# Xray: VLESS + Reality поверх XHTTP — скрипты 04, 05, 06

---

## Как устроено

```
клиент ──► TLS 1.3 (SNI: целевой узел) ──► сервер :443 ──► Xray (VLESS + Reality, XHTTP)
                                                             путь: /download
```

Данные передаются последовательностью HTTP-запросов к пути `/download` в режиме `auto`
(транспорт XHTTP).

**Reality** — механизм установления TLS 1.3-соединения в Xray-core без собственного
домена и сертификата. Клиент аутентифицируется по открытому ключу X25519 сервера и
короткому идентификатору (short id), а параметры TLS-сессии сервер получает от
целевого узла, указанного в конфигурации (SNI).

---

## Варианты Docker-образа

Конфигурация у всех трёх скриптов одна, различается только Docker-образ Xray:

| Скрипт | Образ |
|---|---|
| `04-vless-xhttp-reality-official.sh` | `ghcr.io/xtls/xray-core` |
| `05-vless-xhttp-reality-teddy.sh` | `teddysun/xray` |
| `06-vless-xhttp-reality-choice.sh` | выбирается при установке |

Имя контейнера `xray-xhttp-reality`, каталог `/opt/xray-xhttp-reality`, порт по
умолчанию — 443.

---

## Что спросит установщик

1. **Подключение к серверу** — IP-адрес, порт SSH, пользователь, пароль.
2. **Образ** — только в `06`.
3. **Целевой узел (SNI)** — предлагается значение по умолчанию, можно указать своё.
   Имя проверяется в три этапа: синтаксис, ответ по TLS 1.3 и HTTP/2, затем пробное
   Reality-соединение на самом сервере. Имя, не прошедшее проверку, не принимается.
4. **Порт** — если 443 занят, установщик предлагает освободить его или выбрать другой.
5. **Пользователи** — от 1 до 12, имена из латинских букв, цифр, `_` и `-`, до 32 символов.

До экрана «Начать установку?» сервер не изменяется.

## Что появится на сервере

```
/opt/xray-xhttp-reality/
  docker-compose.yml
  config/config.json
  reality-keys.txt      закрытый и открытый ключи, short id   (права 600)
  users.txt             UUID и клиентские ссылки               (права 600)
```

Журналы контейнера ограничены по размеру: `json-file`, до 10 МБ × 3 файла.

## Важная информация

**Клиенты.** Подходят клиентские приложения на ядре Xray-core. Ядро sing-box транспорт
XHTTP не поддерживает — для таких клиентов подходят конфигурации
[01](01-xray-reality-tcp.md) или [06](06-singbox.md).

**Xray 26.7 и клиенты Reality.** Начиная с версии 26.7 сервер Xray по умолчанию
принимает Reality-подключения только от клиентов на ядре Xray-core (не ниже 26.3.27);
клиенты с собственной реализацией Reality отклоняются, если в конфигурации не задан
`minClientVer`. Менеджер предупреждает об этом при обновлении на 26.7 и выше.
