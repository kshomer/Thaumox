# sing-box: VLESS + Reality, Hysteria2 или TUIC v5 — скрипт 08

---

## Протоколы

Протокол выбирается при запуске установщика.

| Протокол | Транспорт | Сертификат | Особенности |
|---|---|---|---|
| **VLESS + Reality** | TCP | не нужен | TLS 1.3 без собственного домена и сертификата |
| **Hysteria2** | QUIC / UDP | самоподписанный | сохраняет пропускную способность на каналах с потерями пакетов |
| **TUIC v5** | QUIC / UDP | самоподписанный | быстро устанавливает соединение — низкая задержка; поддерживается меньшим числом клиентов |

---

## Самоподписанный сертификат

Для Hysteria2 и TUIC сертификат создаётся на сервере на указанное имя. Клиент проверяет
только совпадение имени, без проверки цепочки доверия: в ссылке ставится `insecure=1`,
а в клиенте должна быть разрешена работа с недоверенным сертификатом.

У Hysteria2 то же имя используется в параметре `masquerade`: на HTTP-запросы без
аутентификации сервер отвечает содержимым сайта с этим именем. Поэтому имя должно
существовать в DNS и отвечать по HTTPS — установщик это проверяет.

## Что спросит установщик

1. **Подключение к серверу** — IP-адрес, порт SSH, пользователь, пароль.
2. **Протокол** — один из трёх.
3. **Имя сервера (SNI)** — для Reality это целевой узел, для Hysteria2 и TUIC — имя в
   сертификате.
4. **Порт.** Reality слушает TCP, Hysteria2 и TUIC — UDP. Поэтому Reality конфликтует с
   другой конфигурацией на TCP 443, а Hysteria2 на UDP 443 может работать рядом с ней.
5. **Пользователи** — от 1 до 12, имена из латинских букв, цифр, `_` и `-`, до 32 символов.

До экрана подтверждения сервер не изменяется.

## Что появится на сервере

```
/opt/singbox/
  docker-compose.yml
  config/config.json
  certs/                для Hysteria2 и TUIC
  server-info.txt       параметры установки          (права 600)
  users.txt             UUID, пароли, ссылки         (права 600)
```

Контейнер `singbox`, образ `ghcr.io/sagernet/sing-box`.

## Важная информация

**Клиенты.** Подходят клиентские приложения на ядре sing-box, а для VLESS + Reality —
также на ядре Xray-core. Hysteria2 и TUIC v5 поддерживаются не всеми приложениями —
поддержку протокола следует уточнять в документации клиента.
