# Thaumox

Набор интерактивных установщиков для развёртывания серверного программного обеспечения
защищённых сетевых соединений — Xray-core, sing-box и WireGuard — на собственном
виртуальном сервере. Установщик запускается на рабочей машине (macOS или Linux),
подключается к серверу по SSH, разворачивает конфигурацию в Docker Compose и
подтверждает результат сквозной проверкой.

Проект предназначен для администрирования собственной инфраструктуры: защищённого
удалённого доступа к своим ресурсам, защищённого обмена данными между устройствами и
серверами, изучения и тестирования сетевых протоколов.

## Особенности

- **Изменения только после подтверждения** — до экрана подтверждения сервер не меняется.
- **Проверка до развёртывания** — имя целевого узла проверяется пробным Reality-соединением,
  конфигурация — самим ядром.
- **Сквозная проверка результата** — временный клиент на сервере подключается по выданной
  ссылке; успех — только ответ `HTTP 204`.
- **Безопасная переустановка** — прежняя установка сохраняется в резервную копию или
  удаляется после подтверждения.
- **Фиксированные версии** — в `docker-compose.yml` записывается номер стабильного релиза,
  а не `latest`.
- **Вход по паролю или SSH-ключу** — одно соединение на весь запуск (ControlMaster).
- **Менеджер установок** — пользователи, ссылки, QR-коды, JSON-профили, смена SNI, версия
  ядра, удаление.
- **Без внешних зависимостей** — bash 3.2 и стандартные утилиты.

## Требования

**Рабочая машина:** macOS, Linux или Windows (через WSL). **Сервер:** Ubuntu 22.04 или
новее, доступ по SSH с правами root.
